# AstroExplorer

Meu primeiro projeto autoral desenvolvido em Python.

## Sobre o projeto

O AstroExplorer será um observatório digital para
exploração de imagens astronômicas reais e informações
sobre objetos celestes.

## Objetivos de aprendizagem

- Fundamentos de Python
- Lógica de programação
- Git e GitHub
- Consumo de APIs
- Análise e visualização de dados astronômicos

## Estado atual

Projeto em desenvolvimento.

python3 main.py
